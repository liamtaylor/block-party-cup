# Block Party Cup

A Minecraft-style party game for 2–4 players on one screen: Block Soccer, Water Polo, Surf Showdown and Mob Hunt. Play the full four-round cup or any game on its own. Built for a 9th birthday.

**Play:** https://liamtaylor.github.io/block-party-cup/

## Controls

- Keyboard: W A S D + Space, Arrows + Enter, I J K L + U, T F G H + R, or Numpad + 0
- Game controllers (including Xbox): press a button on each one, then choose "Use controllers" on the start screen. D-pad moves through menus, A selects, Start begins or pauses.

## Editing

`block-party-cup.html` is the source. It is also published as a claude.ai artifact, so it has no `<!doctype>`/`<head>` of its own.
After changing it, run `node build.js` to regenerate `index.html`, which is what GitHub Pages serves.
