# Block Party Cup

A Minecraft-style party game for 2–4 players on one screen: Block Soccer, Water Polo, Spleef, Surf Showdown, Penalty Shootout and Mob Hunt. Play the full six-game cup or any game on its own, then finish with Birthday Cake Defence, a team bonus round where everyone protects the cake from silverfish. Built for a 9th birthday.

**Play:** https://liamtaylor.github.io/block-party-cup/

## Controls

- Keyboard: W A S D + Space, Arrows + Enter, I J K L + U, T F G H + R, or Numpad + 0
- Game controllers (including Xbox): press A on any controller to open the controller lobby. Each player presses A to join, left/right picks a character, up/down picks the game, and the Menu button (☰) or View button plays. No pointer needed: every screen shows which button does what (A continue, B back, Menu/View pause).

## Editing

`block-party-cup.html` is the source. It is also published as a claude.ai artifact, so it has no `<!doctype>`/`<head>` of its own.
After changing it, run `node build.js` to regenerate `index.html`, which is what GitHub Pages serves.
